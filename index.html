개인 AI 프로젝트 · 데모 구현

폐의류 분류 및 XAI 선별 보조

약 3,000장의 이미지로 블라우스·코트·재킷의 종류와 정상·비정상 상태를 분류하는 선별 보조 데모를 만들었습니다.

분류 파이프라인
EfficientNetV2-S로 의류 종류를 예측하고, 해당 종류의 상태 분류 모델을 호출했습니다. 상태 모델에는 ECA 채널 어텐션, 공간 어텐션과 GeM Pooling을 적용했습니다. Streamlit에서 분류 결과, 히트맵, PDF 리포트를 제공했습니다.
시각화 검증
정답을 맞힌 사진에서도 배경이 강조돼 분류 성능과 XAI 품질을 따로 확인했습니다. Grad-CAM++, EigenCAM, Saliency를 비교하고 의류·테두리 마스크로 강조 분포를 계산했습니다. 타깃 레이어는 공간 어텐션 층에서 백본의 합성곱 층으로 바꿨습니다.
실험 결과
의류 종류 분류 검증 정확도 93.98%, Macro F1 0.9399. 별도 XAI 평가의 의류 영역 집중도는 평균 0.8415였습니다. 기록된 분류 모델 추론 실험에서는 TorchScript 적용 후 평균 67.59ms → 11.68ms였습니다.

평가 수치는 프로젝트의 실험 환경에서 측정했습니다.

팀 프로젝트 · 백엔드 담당

기업 간식 구독 추천 서비스

기업의 자연어 요청을 예산과 상품 조건이 반영된 주문 조합으로 바꾸는 서비스를 개발했습니다. 팀의 추천 엔진을 FastAPI에 연결하고 AWS EC2 배포와 RDS PostgreSQL 연동을 맡았습니다.

API와 데이터
POST /api/recommend-ai로 추천 결과를 제공하고, GET /api/products는 RDS 상품 조회와 연결했습니다. 자연어의 예산·구성비·제로 음료 포함 및 제외 조건을 반영하고, 적용한 조건을 응답에 포함했습니다.
프론트엔드 협업
recommendations에는 추천 순서를 유지하고 category_grouped_recommendations에는 분류별 목록을 제공했습니다. 상품에는 DB 원본 분류를 표시하고, 화면의 구성비는 상위 그룹으로 집계할 수 있게 했습니다.
테스트
제로 음료 제외 요청에서 추천 탭의 제로 음료가 0개인지 검증했습니다. 상품당 최대 30개 제한과 예산별 품목 수도 확인했습니다. 낮은 단가를 우선하는 일부 고예산 조합에서는 잔액이 크게 남을 수 있었습니다.

Metaroad 그룹웨어 & 스케줄링/알람 시스템

Metaroad (직영/가맹 센터용 그룹웨어)
기술 스택 : Python 백엔드, 스케줄러 모듈(scheduler.py v2)
주요 기능 : 직영/가맹 센터 출결·송영·반복업무 통합 관리, 알람/배치 작업 자동화, 반복업무 스케줄링

직영/가맹 센터의 업무(출결, 송영, 반복업무)를 통합 관리하는 웹 기반 그룹웨어로, Python 백엔드와 스케줄러 모듈(scheduler.py v2)을 중심으로 알람·배치 작업·반복업무 자동화를 구현한 시스템입니다.

추가 설명:
Metaroad는 센터 운영에 필요한 출결·송영·반복업무 데이터를 하나의 웹 그룹웨어에서 통합 관리하는 실무형 프로젝트입니다. Python 기반 REST API(업무/출결/송영/알람 도메인)와 ORM(SQLAlchemy) 구조를 직접 설계하고, APScheduler 기반 스케줄러 엔진(scheduler_v2.py)으로 알람 발송 및 반복업무 롤오버(일·주·월·분기·반기·연간 규칙) 자동화를 구현했습니다. Celery·Redis 기반의 비동기 작업 처리로 대량 알림/배치를 분리하여 안정성을 높였으며, React 기반 관리자/센터 대시보드 일부 화면 개발에도 참여했습니다.
